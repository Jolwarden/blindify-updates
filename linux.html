Installation

Double-cliquez sur le fichier téléchargé, ou depuis un terminal : 

sudo apt install ./Blindify_amd64.deb

Le ./ est nécessaire, sinon apt cherchera un paquet dans ses dépôts. Les dépendances audio sont installées automatiquement.

Configuration requise

  • Debian 12, Ubuntu 22.04 ou ultérieur, et dérivés (Mint, Zorin, Pop!_OS)
  • Architecture 64 bits (x86_64)

Les autres distributions ne sont pas prises en charge pour le moment.
