⚠️ Application non signée

macOS bloquera l'ouverture au premier lancement. Le clic droit ne suffit plus depuis macOS Sequoia : la procédure passe par les réglages système.

  1. Ouvrir l'application une première fois — un message de blocage apparaît.
  2. Aller dans Réglages Système → Confidentialité et sécurité.
  3. Faire défiler jusqu'au message concernant Blindify, puis cliquer sur Ouvrir quand même.

Si un message signale que l'application est endommagée, exécutez dans le Terminal : xattr -cr /Applications/Blindify.app

Configuration requise

  • macOS 11 Big Sur ou ultérieur
  • Apple Silicon
